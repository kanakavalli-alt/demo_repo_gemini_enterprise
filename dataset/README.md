This directory should contain the 'cats' and 'dogs' subdirectories with the respective training and testing images.

Due to the large size of image datasets (often hundreds of megabytes to gigabytes), they cannot be directly uploaded via the agent API. 

Please manually download a dataset (like the Kaggle Dogs vs. Cats dataset) and extract it here so that the folder structure looks like:
- dataset/cats/cat1.jpg
- dataset/cats/cat2.jpg
...
- dataset/dogs/dog1.jpg
- dataset/dogs/dog2.jpg
